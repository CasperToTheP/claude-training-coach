# Useful coach commands

## Initial setup
```text
/onboard
```

For a structured running race:
```text
/training-plan
```

## Daily
```text
/today
```

## Weekly
```text
/sync-week
/review-week
/plan-week
```

## Running-specific deeper review
```text
/running-coach
```

## One workout
```text
/review-session
```

## Strength
```text
/strength-session
```

## Dashboards
```text
/multisport-dashboard
```

The original running dashboard is also preserved:
```text
/training-dashboard
```

## Example natural-language prompts

```text
Use all connected data sources. What should I train today?
```

```text
Sync the previous Monday-Sunday week, de-duplicate Garmin and Strava, then review it.
```

```text
Review yesterday's intervals against my current race plan and show whether pace or HR faded across reps.
```

```text
Plan next week. Preserve the key workout from my macro race plan but adjust the rest around recovery and my cycling/strength load.
```

```text
Log this strength session: squat 70 kg 3x8 RIR2; RDL 60 kg 3x8 RIR2; calf raises 3x15 RIR1.
```
